## 2026-11-14 · V10.46 · P0 TestFlight：手绘画完无法退出 / 选中 / 保存

**报告**：用户在真实 iPhone（TestFlight，0.1.0 (1)）上测试手绘：可以画，但画完后页面无法选中或操作，没法顺利保存。

**调查范围**：完整流程，从进入手绘 → 画 → 完成 → 回到 Studio 选中、移动 → 保存 → 阅读器 → 再次编辑。
- **网页**：Chromium 模拟 iPhone 13 + 触摸。
- **iOS 模拟器**：Debug 构建，用 XCUITest 发送**真实触摸**（按下、拖动、抬起都经过 iOS 触摸系统）。另有一个只读探针，每 200 ms 把页面状态写进无障碍标签：画板是否打开、选中的是什么、手指按下和抬起的次数。测试工程只放在 `/tmp` 的副本里，没有改仓库里的 Xcode 工程。

结果是**四个互相独立的问题**，分开记录：

### A. 画板的「取消 / 完成」在 iPhone 状态栏下面，点不到 → 卡在画板里（TestFlight 上的直接原因）

- **现象（模拟器，真实触摸）**
  - 画完点「完成」后，页面一次按下事件都没收到（按下次数停在 3 次）。
  - 画板一直开着，草稿里没有手绘图层。之后所有点击都落在画板里。
  - 截图：「取消」在时间后面，「完成」在电池图标后面。
- **根因**
  - 画板在手机上占满整个屏幕（`height: 100dvh`）。底部留了 Home 指示条的位置（`safe-area-inset-bottom`），顶部却没留状态栏的位置（`.draw-top { padding: 10px 14px }`）。
  - iOS 会把状态栏区域的点按留给系统，所以这两个按钮点不到。
  - 网页预览没有状态栏，所以网页上一直正常。
- **修改**：`Public/styles.css` 里的 `.draw-top`，上边距改为 `calc(10px + env(safe-area-inset-top))`。
- **验证（模拟器，真实触摸，同一个测试脚本）**
  - 修复后，点「完成」→ 画板关闭，出现手绘图层。
  - 点笔画能选中（出现「接着画」工具）。
  - 拖动能移动（移动了 30 pt）。
  - 点「完成」保存 → 进入阅读器，已保存的手绘有 1 个。
- **排除的猜测：「幽灵手指」**。我曾怀疑手指抬起的事件丢失，导致后面的单指点击被当成双指。真实触摸下按下和抬起始终一一对应，所以这个猜测被排除，相关代码没有改。

### B. 手绘透明的部分挡住下面的照片 / 文字 / 贴纸（任何设备都会出现）

- **现象（网页）**
  - 一张手绘是一张图片，大小等于「画到的最外边」围成的方框。
  - 两笔离得远时，这个方框盖住大半页（图层宽高超过 60%）。
  - 方框下面的文字点不到，点了会选中手绘。
- **根因**：图层元素整个方框都接收点击，包括透明的地方。
- **修改**：`Public/app.js` 的 Studio 按下事件处理。
  - 按下的位置如果落在手绘上，先查手绘在这一点约 14 px 范围内有没有笔画。
  - 每张手绘只在第一次时读一次透明度，最长边缩到 400 px，存起来重复用，旋转、缩放都算进去。
  - 没有笔画时，这次点击交给下面的照片、文字或贴纸；下面什么都没有时，仍然选中手绘。
  - 透明度读不到时，保持原来的行为。
- **验证（网页 v145）**
  - 点被手绘方框盖住的文字 → 选中文字。
  - 点笔画 → 选中手绘。

### C. 「取消」会直接丢掉新画的笔画

- **修改**：`Public/js/draw.mjs` 新增可选参数 `confirmDiscard`。
  - 有新笔画时点「取消」，或用系统返回 / Esc 关闭，会先用页面内的确认框问一句。
  - 没有新笔画时直接关闭。
  - 接着画以前的手绘时点取消，原来的手绘不变（`mediaRef` 和位置都不变）。
- **验证（网页 v145）**：确认框里选「取消」→ 留在画板；选「确定」→ 只丢掉新笔画。

### D. 手绘保存失败时直接丢失

- **修改**：`Public/app.js` 的 `drawOnPage`。写入媒体失败时，画好的内容留在内存里，用确认框问「再试一次吗？」。
- **验证（网页 v145）**：模拟第一次写入失败（设备空间已满）→ 出现重试问题 → 选「确定」→ 保存成功。

### 不是问题的部分

- **从首页「手绘」进入时的目标页面**：开始画之前，就已经在今天、最近用过的那本手帐里新建了一页（会提示「写在《…》里」）。画完不需要再选页面。
- **空白画板点「完成」**：不会生成手绘图层。

### 仍需在真机（TestFlight）上确认

1. 在 iPhone 上画完点「完成」，能回到页面。
2. 点笔画能选中，能移动，双指能缩放。
3. 点手绘空白处，能选中下面的照片或文字。
4. 保存后从多任务里划掉 App，重新打开，手绘还在。

### 回退

`git revert` 这一次的提交即可。数据格式没有变化，回退后旧版照常读取。
