# Captain 重新定位：小小的记忆陪伴（方案，等确认）

> 2026-11-13。*Captain is a little memory companion, not another general-purpose chatbot.*
> 预览（375 中文 / 430 English）：https://claude.ai/artifact/KgAuNDg4mgsgKYhUbDyj1A 第二部分。截图来自临时原型，没有改正式代码。
> 优先级：排在 Quick Create 排版质量和媒体保存可靠性之后。这一轮只出设计。

## 现在的功能是否有用户价值

| 现在面板里的东西 | 价值 | 建议 |
|---|---|---|
| 打开时的状态句（「今天有一页了，不错。」） | 只是一句话，点了不会发生任何事 | 换成按情况变化的卡片，带能直接用的按钮 |
| 整理今天的故事 | 和日历里这一天的页面列表重复 | 去掉，由状态 C 的「打开今天」代替 |
| 回顾以前的回忆 | 和首页的 On this day 重复 | 只在真的在看旧手帐时出现（状态 D） |
| 帮我写一句话（需要 AI 小管家，还没有开放） | 看起来能点，其实做不了 | 去掉 |
| 和 Captain 聊聊 | 聊天框本来就在下面 | 去掉这一行，保留输入框 |
| 玩耍、装扮 | 可选的乐趣 | 保留；玩耍页的提示只在第一次显示；去掉「My Little Keeper · 温柔」小标题 |

## 新结构

- 顶部：Captain 的图和名字；下面是 聊天 · 玩耍 · 装扮。
- 聊天页最上面是一张状态卡片：一句话，加一到两个按钮。下面是聊天记录和输入框。
- 不复制日历、我的书这些已有的导航。

## 四种状态

| 状态 | 何时 | Captain 说 | 操作 |
|---|---|---|---|
| A | 今天还没有手帐 | 今天还没有记下什么。挑几张照片，我帮你排成一页。 | 〔选照片〕〔随手写一句〕 |
| B | 15 分钟内刚做完一页 | 这一页排好了，2 张照片。想写一句话吗？不写也很好。<br>（已经写了字：这一页排好了。） | 〔写一句话〕〔看看成品〕 |
| C | 今天已经记了 | 今天记了 1 页。 | 〔打开今天〕 |
| D | 30 分钟内刚在阅读器里看旧手帐 | 刚才在看 11月12日的「睡前读了几页书」。 | 〔接着往下翻〕〔回到今天〕 |

文案只用事实：日期、张数、页数，以及用户自己写的标题或文字（V10.27 的展示名规则）。不推测心情，不编造回忆，不说没有做到的事。

## 最小实现（不加 AI）

- 状态判断只用已有的数据：今天的页面、刚保存的页面、阅读器最后打开的页面。后两项只记在内存里。
- 按钮复用现有功能：首页选照片、随手写、`read-page`、`read-edit`、`openReader`、翻页。
- 聊天：本机规则照旧回复；本机 Qwen 只在开发模式评测。这一轮不再加关键词。
- 改动范围：`app.js` 的 Captain 面板（`keeperActsHTML`、`openKeeperPanel` 的开头），加 8 条中英文案。不动玩耍和装扮的逻辑。
