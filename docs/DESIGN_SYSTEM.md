# Little Days · 视觉规范

方向：精品文具店的克制界面，搭配有温度、可自由创作的纸张与素材。默认界面留白、柔和、易读；创作画布可以丰富。避免把成长页面做成高压任务清单。

## 颜色

权威来源：`Packages/LittleDaysCore/Sources/LittleDaysCore/Resources/design-tokens.json`。

| 名称 | Token | 色值 | 用途 |
| --- | --- | --- | --- |
| Cream White | cream | #F8F5EF | 主背景 |
| Soft Ink | ink | #2F2A26 | 主文字 |
| Blush Pink | blush | #E8CFCF | 封面、胶带、柔和强调 |
| Sage Green | sage | #C9D7C1 | 成长、自然与积极状态 |
| Powder Blue | blue | #D8E3EE | 分类与封面 |
| Butter Yellow | butter | #F3E7B3 | 温暖纸张与封面 |

辅助色：accent #7D8D6D、muted #8D857B、line #E8E1D7、paper #FFFDFA。浅色只用于装饰/填充，不单独表示状态；完成按钮同时显示勾选与 `aria-pressed`。

Web 运行时加载共享 JSON。`Public/tokens.css` 是加载前的回退，由 `python tools/sync_tokens.py` 自动生成；禁止手工修改后形成第二套颜色源。SwiftUI 从同一资源解码生成 Color。

## 字体与层级

- 品牌与英文页标题：Georgia / 系统 Serif；中文主文案：平台系统黑体；手帐温柔宋体采用 Songti SC / SimSun 回退。
- 保留旧 Rounded / Serif / System 字体，同时加入 Cormorant Garamond、Caveat、Quicksand、Libre Baskerville、DM Sans、Pacifico、Ma Shan Zheng 的实际本地 TTF；每款附 SIL OFL，可按许可用于商业 App。
- iPhone 内容区标题 25–30 px；区域标题 14–17 px；正文随场景 11–15 px；小型英文标签仅作辅助，不承载唯一操作说明。
- 原生主界面采用系统字体与语义字号，手帐可选择授权字体；后续须做 Dynamic Type 与 VoiceOver 实测。

## 布局与组件

- 优先 iPhone 375 / 390 / 430 宽；主内容左右边距 23 px，区域间距 20–24 px。
- 卡片圆角约 18–22 px，按钮约 12–14 px；边框轻、阴影少。
- 底部五个入口固定可达，Studio 以绿色创作按钮突出；页面内容独立滚动，避免导航随内容消失。
- 桌面浏览器展示 iPhone 预览框及品牌留白；手机宽度填满视口。外框/顶栏始终明确 Web Preview 身份。
- 习惯完成态：勾选 + 柔和绿色；草稿显示保存中/已保存/失败反馈；模态表单支持取消与键盘输入。
- 贴纸同时提供触控拖动与位置/大小/旋转滑杆，键盘可选择贴纸并使用滑杆调整。

## 创作语言

| 风格 | 表现 |

| Cute | 奶油点阵纸、粉色胶带、花朵/水果/小动物 |

## V3 · 精品书架与封面系统

- 六种封面：Minimal Linen / Vintage Leather / Floral Notebook / Pastel Cute / Travel Album / Scrapbook Collage。
- 使用书脊、细边框、亚麻/皮革/拼贴质感、原创图形和有层级的标题，不用纯色块加 Emoji 代替设计。
- 允许封面照片、颜色、字体、装饰；编辑时即时预览。封面字体跟随实际字体文件，用户标题不自动翻译。
- 书架保留 2 列主封面与 Home 3 列缩略封面；小尺寸标题控制行数，长标题在详情完整显示。

## V3 · 字体、贴纸与媒体

字体分类为 Elegant Serif、Handwritten、Cute Rounded、Vintage、Minimal Sans、Decorative、Chinese Fonts。权威资源是 library.json；CSS 由 tools/sync_library.py 生成。TTF 原文件保留作者/保留名称与 OFL，不把“看起来像手写”的系统回退冒充实际字体。

原创贴纸十类 23 款，使用统一的暖灰描边、柔粉/鼠尾草/奶油色与留白。SVG 透明背景、可无限缩放；480px 透明 PNG 供 SwiftUI。旧 Emoji 图层保留兼容，新的素材选择器优先原创图形。

音频与视频卡片是纸张感容器、简短标题、低干扰工具和浏览器原生播放控件；视频可指定封面。录音时清楚显示状态/秒数与停止按钮，失败不假报已保存。V6.0 起有一个小的原创背景音乐目录：选曲在底部面板里（试听圆钮 + 曲名/心情/时长 + 「用这首」），页面上只出现一个小的「♫ 曲名」胶囊按钮，播放时音符轻轻跳动（尊重减少动态效果）。不暗示已有音乐平台、剪辑或转写。

## V3 · 双语与用户内容

- 共享 i18n.json 为 UI 文案唯一来源；Settings 切换简体中文/English，五页、表单、按钮、错误与状态都有对应词条。
- 用户的书本名称、正文、字段值、文件名和音视频不自动翻译。
- 系统字段预设标签可以双语；用户改写标签后视为自己的内容。日期/数字使用当前 locale，后续货币控件也必须显式指定币种与 locale。
- 英文按钮允许自然换行，保持 375/390/430 宽度无严重横向溢出。授权链接放在 Settings，不占据主要创作流程。
- Private 为唯一可用可见性；Public / Shared 暂禁用并解释后续阶段，不用“开关已打开”的演示误导用户内容已经被安全分享。

## V3.1 · 自由画布、章节与回忆阅读

> V3.2 更新：Studio 改为“创作桌面”——缩小的预览固定在顶部（⤢ 放大），下方是概括菜单，每行图标 + 名称 + 当前值，点开显示细节；纸张用小样张直接展示花纹。成长轨迹是一本小书：书脊、点纹封面、横线内页、龙藏体日期与霞鹜文楷心得。手帐本每天一张封面：最多三张错落拍立得 + 大号日期 + 小故事列表。

- **Studio 像创作桌面**：画布下方是“添加照片 / 撤销 / 重做”三联工具条与五种版式缩略图；选中图层时在图层内显示右下角调整大小、顶部旋转圆点，选中层临时抬高便于操作（保存的叠放顺序不变）。触屏把手 24px，鼠标 18px。
- **照片相框**：拍立得（下边留白）、白边、圆角、无边框；可加半透明和纸胶带。所有尺寸使用 `cqw`/百分比，随画布等比缩放。
- **Moments = 章节**：Studio 顶部“今日小故事”目录卡（编号、时间、标题、缩略图，可折叠），当前章节左侧鼠尾草色竖线。Day Detail 每章为一张纸，顶部轮流使用粉/绿胶带，“第 01 章”+时间胶囊+手写标题+标签。
- **Day Detail**：点纹报头（日期、统计、心情印章）→ 章节目录 → 当日主页 → 各章节 → 成长便签；只读画布点击照片进入白边灯箱。
- **音频播放器**：圆角胶囊、鼠尾草色圆形播放键、进度条与时间、五条声波（播放时轻微跳动，遵守 reduce motion）；“音频 / 语音日记 / 视频”小标签区分来源。
- **日历标记**：照片 #D7A59C、视频 #8FA7BD、声音 #D5B555、成长 #8FA57D 的 4px 圆点，多 Moments 显示小数字；不改变原格子尺寸。
- **成长感想**：横线便签纸、手写字体的感想文字；成长卡片为浅奶油底+浅鼠尾草描边，可放入画布。
