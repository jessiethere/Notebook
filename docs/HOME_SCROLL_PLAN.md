# Home Scroll Experience（设计轮 · 2026-11-11 · 等待确认，未改 App 代码）

目标：首页从上滑到底是一条连续的体验 **Create → Remember → Collect**，而不是「顶部像精品 App、中间像博客、底部像电商」。顶部 Direction A 不动，只重做中下部。

设计稿：Design 画布 https://claude.ai/artifact/4tXVQfHSSPvQxJZqJFPTUG 最下面一行（整页新旧对比、四个连续滚动位置、分区对比、各种变体）。图片是在**真实首页**上注入原型后用 Chromium（393×852 等）截的，内容是同一份真实数据（今天两页手帐、两件待办、三本手帐）。原型文件在 docs/prototypes/home-scroll/。

## 1. 结构

| 段落 | 现在 | 新设计 |
|---|---|---|
| Create | Direction A（品牌、大日期、Captain、照片手帐主卡、三个次入口、补记） | **不变** |
| Remember | 「今天的回忆」：每张照片一张大图卡片，横向滑动；大图 + 标题 + 正文 +「打开 ›」 | **Today's Story**：一页排好版的纸——主照片 + 1–2 张小照片（拍立得、轻微错落、一条胶带），日期行、标题、两行感想、页码「01 / 02」和「翻开这一页 →」；当天其他页面在下面各占一行（小拍立得 + 名字 + 时间） |
| （辅助） | 「今天要做的事」大卡片（标题、说明、列表、输入框）+「我的习惯」一行 | **一行**：`☐ 今天要做的事 · 还有 1 件 ▾ ｜ 习惯 0/3 ›`；点左边展开成一张安静的横线便签（勾选、删除、添加都和现在一样），点右边去习惯 |
| Collect | 「书架」：三本等大的封面横排，每本下面 名字 + 分类 · 篇数 +「记一页」按钮；我的书 / 共同的书 切换 | **My Library**：一层小书架——最近在记的那本大一些（有书脊、书页厚度、轻微倾斜），旁边写「正在记录 · 书名 · 4 篇 · 今天更新 · 接着记一页 →」；其他手帐小一号立在同一层上，只留封面和名字；更多用「+N」；「全部 ›」进书架页 |
| 结尾 | 一句英文引语 | 同一句，用品牌衬线斜体，上面一条短线，像书的版权页 |

统一的东西：段落标题都是「英文衬线斜体标题 + 中文小字副题」（`LD-elegant` 27px + 12px 字距 .14em，和顶部 PHOTO JOURNAL 的 kicker 同一套）；纸张都是 `--paper` + 同一种柔和长投影；动作都是鼠尾草绿文字链接或顶部那一个胶囊按钮（下半页不再出现第二个实心按钮）；照片都用同一种拍立得（白边、底边略宽、±2–4°）。

节奏：顶部是明确的一张卡 + 一个按钮；中部是全页最大的一张纸、以照片为主；待办只是两条发丝线之间的一行；底部没有卡片底，书直接立在一条牛皮纸色的搁板上。

## 2. Today's Story 的规则

- **选哪一页**：当天最新的、带照片的页面做主故事；没有照片的页面用「引语」版式（大引号 + 标题放大）。当天其他页面最多列 2 行，再多显示「全部 N 页 ›」。
- **照片数量**：1 张 = 一张居中拍立得；2 张 = 主图 + 右下小图；3 张及以上 = 主图 + 右侧两张小图，更多显示「+N」。照片区固定 236px 高、`object-fit: cover`、带占位底色和宽高属性，图片加载前后不跳动。
- **文字**：标题最多两行，感想最多两行（超出省略）；只保留日期行、时间、页码三项元数据。
- **视频 / 声音**：主图左下角一个播放标记，文字下方显示「▶ 0:12 · ♪ 0:31」小标签；点进去在页面里播放（与现在一样，首页本来就不内嵌播放器）。媒体仍只存在 IndexedDB。
- **真实数据**：只显示用户自己保存的页面；示例内容不会冒充用户内容。
- **空状态**：一张虚线拍立得轮廓 +「今天还没有留下故事 · 一张照片、一句话就够了 · 选一张照片 →」（动作同顶部主按钮）。
- 连续记录的小圆点文字保留在段落标题右侧（点开仍是原来的连续记录面板）。

## 3. 功能去向（不删除任何功能）

| 现有 | 去向 |
|---|---|
| 今日照片横向滑动（每张照片一屏） | 合并成一页排版；完整内容点卡片进入当天 |
| 「打开 ›」 | 整张卡可点 +「翻开这一页 →」 |
| 待办：添加 / 勾选 / 删除 / 「把昨天没做完的带过来」/ 最多 8 件 | 都在展开后的便签里，逻辑不变 |
| 待办说明「写下今天要做的，做完打个勾 · 最多 8 件」 | 只在展开时显示 |
| 我的习惯 0/3 | 同一行右侧，点击去习惯页（不恢复独立 Growth 模块） |
| 每本书下面的「记一页」 | 只有精选那本有「接着记一页 →」；其他书点封面进入后再记 |
| 分类 · 篇数 | 精选那本显示「篇数 · 最近更新」；其他只留名字 |
| 我的书 / 共同的书 切换 | 建议移到书架页（见第 6 节问题 3） |

## 4. 真实滚动检查（原型，Chromium 触屏模拟）

- 首屏不变；「Today's Story」标题刚好露在首屏底部，提示可以往下看。
- 393×852 下整页高度 1875px（现在 1914px）：内容更多（故事卡更大），但待办从约 230px 缩到 54px。
- 375×667、393×852、430×932：没有横向溢出，原型区域内没有元素超出屏幕宽度。
- 英文文案（Today's Story / To do today · 1 left / Habits / CONTINUING / Write the next page →）：未换行溢出。
- 底部导航固定（沿用现有实现）；原型没有新增滚动监听或动画，只有静态旋转和阴影。
- 没验证：iPhone 真机 / Safari / WKWebView；真实相册照片的各种比例（原型用的是素材库照片）。

## 5. 实现可行性

**Web（`Public/`，实际运行的界面）— 可行，增量修改，不动数据结构**

- `home()` 里三处模板替换：`.v9-today` → 故事卡（数据就是现在轮播用的当天页面与照片）；`.today-planner` → 一行 + 可展开便签（复用现有 `.today-plans` 列表和 `plan-*` 动作；展开状态记在本机 LocalStorage，属于界面偏好）；`.home-books` → 小书架。
- 「最近在记的那本」= 该手帐本最新一页的更新时间最大者（现有数据可算，不加字段）。
- 封面缩小：现有 `.book-cover` 内部字号是固定像素，原型用「按原尺寸渲染 + CSS `zoom: .5`」得到小封面；正式实现建议同样做法或改成容器单位，需要在 Safari 上确认。
- 需要同步修改的测试（估计 6–8 套）：依赖 `.today-peek` / `.peek-slide` 轮播、`.today-planner`、`.home-book` / `.home-book-write`、首页「我的书 / 共同的书」的用例（v45、v57、v63、v68 等）；新增一套首页滚动用例（不同照片数量、空状态、展开待办、三种屏幕、英文）。
- 风险：低–中。主要是测试迁移和小封面在 Safari 的渲染；无数据迁移。

**SwiftUI — 不需要单独实现**

- 2026-11-07 确认的架构是 Swift 外壳（WKWebView）加载同一份 `Public/`，`tools/sync_native_web.py` 同步即可，iOS 上看到的就是这套页面。
- 保留的 SwiftUI 原型视图（`LittleDaysRootView` 等）本轮不更新。如果将来要原生重写：`ScrollView` + `LazyVStack`，照片错落用 `ZStack` + `rotationEffect`，待办用 `DisclosureGroup`，书架用 `HStack(alignment: .bottom)`，都是常规写法；但那是另一项工作，且目前容器里没有 Xcode，Swift 从未编译验证过。

## 6. 需要你确认的 4 件事

1. **段落标题用英文**（Today's Story / My Library，中文在副题里）可以吗？品牌衬线字体只有拉丁字母；另一种做法是标题直接用中文黑体（今天的故事 / 我的手帐）。
2. **待办默认收起**，并记住你上次是展开还是收起——可以吗？（另一种：有未完成事项时自动展开。）
3. **「共同的书」切换从首页移到书架页**可以吗？（它属于 Labs 里的共享手帐，普通安装看不到。）
4. **今天还没记录时**，只显示空状态；还是在空状态下面再放一条「最近的故事 · 昨天」？

确认后按 Step 3 实施（增量修改 `home()` 与样式、迁移测试、真实截图、更新 agent.md / README / DESIGN_SYSTEM / PRODUCT_SPEC，一起提交）。
