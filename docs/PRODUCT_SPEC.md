# Little Days · 产品需求与阶段范围

核心理念：**记录生活的美好，也收藏一点点变好的自己。**

产品是一款 iPhone 数字手帐 App，像一家温柔、精致、有创作灵感的数字文具店。最终客户端使用 Swift / SwiftUI；Windows 浏览器提供独立的 HTML 交互预览，不能称为实际运行的 SwiftUI。

## 全量产品目标

| 模块 | 目标能力 |
| --- | --- |
| Home | 当天日期、每日手帐和照片；快速添加照片/文字/心情/打卡；当天习惯；最近编辑的手帐本；Studio 入口 |
| Calendar | 月份切换、任意日期浏览、历史补记与编辑、记录标记或缩略图；Memory / Growth 两种视图 |
| Growth | Fitness、Learning、Wellness、Creative Life 与自定义主题；完成型/时长型习惯；每日记录、每周目标、历史日历、里程碑；通过日期关联 Journal |
| Journal Studio | Quick Create 与 Creative Mode；照片添加/替换/裁切；标题/正文/字体；贴纸/胶带/相框/背景；照片和贴纸拖动、缩放、旋转；图层顺序、模板、自动排版、撤销/重做、草稿与图片导出 |
| My Books | Travel、Food、Daily Life 等主题手帐；自定义封面；跨日期内容归类、查看与编辑 |

## 第一阶段已实现

### Windows Web 预览

- iPhone 比例界面；Home、Calendar、Growth、Studio、My Books 五个可点击入口，触屏/鼠标均可操作。
- 精致 Home：动态本机日期、照片拼贴、今日手帐、快速入口、习惯状态、最近编辑手帐本与 Studio 入口。
- 日历按月切换、返回今天、任意日期查看/补记/修改；Memory 显示照片或心情标记；Growth 显示次数并可补打卡。
- 自定义习惯名称/主题/每周目标；完成型打卡；时长型输入分钟；取消打卡、周进度、当周历史点阵、累计三次的小花里程碑。
- Growth 与 Journal 使用相同本地日期键 `YYYY-MM-DD`，Studio 自动显示当天关联打卡数量，不复制一份打卡数据。
- Quick Create：标题、正文、照片上传/替换、心情、字体与三个模板，使用固定模板自动排版。
- Creative Mode：Cute / Minimal / Vintage 文字/Emoji 贴纸，添加、拖动、缩放、旋转、位置滑杆、上下图层与删除；30 步内存撤销/重做。
- 自动草稿、显式保存草稿、重新打开恢复；保存日记、基础 PNG 图片导出。
- 自定义手帐本名称/主题、Emoji 封面与颜色，按手帐本查看和编辑记录。
- 浏览器本地持久化；初次包含清楚标记的示例手帐，保存后转为用户记录。未提供删除/重置操作。

### 原生 SwiftUI 基础

- 提供 iOS 17+ App 工程、独立 UI Swift Package 和不依赖 Vapor 的共享 Core Package。
- 五个原生导航页面；Home 视觉基础、日期选择与历史记录、默认时长/完成打卡、周进度、文字/心情/模板编辑、手帐归类、草稿/记录本机文件保存。
- 共用 Core 中的设计颜色、导航/模板/素材定义、示例 JSON、照片和数据类型。
- 原生 UI 尚未完成 iOS SDK 编译/模拟器/真机验证；Web 预览验证不能替代原生验证。

## 后续阶段

1. 编辑器：照片自由裁切/移动/缩放/旋转，多照片，自由文本框，可选相框/胶带素材，精确的所见即所得导出；将 Web 已验证交互移植到原生。
2. 数据：从 Web LocalStorage 迁移到 IndexedDB / 文件备份导入导出；原生可靠媒体文件管理、迁移和两端交换协议。当前两端不会自动同步。
3. 原生：PhotosPicker、拖拽手势、自由编辑画布、自定义习惯与手帐本；动态字体、VoiceOver、真机性能与图片导出验证。
4. 成长：习惯编辑/归档、提醒、更多里程碑和连续打卡统计。
5. 商店：原创或明确授权的贴纸/字体/纸张素材库，收藏/下载与主题包。
6. 发布：App 图标、签名与团队配置、iCloud（另行设计）、隐私说明、TestFlight 与 App Store 流程。

## 当前边界

- 当前单用户、本机、离线数据模型；预览首次运行不需要联网下载素材，图片已随仓库保存。
- 每个日期一篇 Journal，每篇归入一本手帐；时间键按设备本地日历生成，不用 UTC 截断日期。
- Web 照片导入先缩小至最长边 1000 像素，并转为 JPEG。单文件上限 20 MB；LocalStorage 总容量受浏览器限制，空间不足会显示失败。
- 预览关闭/刷新可恢复已保存数据；清理站点数据、更换浏览器或更换 localhost 端口会使用不同存储。请先导出重要创作。
- 字体选择当前使用系统字体回退；Emoji 图样随操作系统不同；素材库还不是完整文具商店。
- 图片导出采用独立 Canvas 基础排版，长文截断、字体与预览可能有差异；不是完全所见即所得。完整文字仍保存在记录中。

## 第一阶段验收

Windows 可用一个命令启动 localhost；无需 Xcode；用户能进入五页、输入内容、打卡、补记、保存、刷新恢复并导出图片。文档必须列明 Web / 原生进度差异、真实测试结果和剩余工作；更新日志随代码提交。
