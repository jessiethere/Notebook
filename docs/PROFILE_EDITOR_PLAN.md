# 编辑资料：Personal Stationery（2026-11-11 · 设计预览，等待确认；未改 App 代码）

设计预览一张（PROFILE_EDITOR_PREVIEW.png，已直接发给用户，未放进仓库）。它是在真实 App（提交 544664e）的设置页上运行时注入原型后用 Chromium 截的，模拟 iPhone 393×852 和 375×667，**不是真机**。键盘是画上去的灰色示意块，不是真实键盘。

预览包括这些画面：
- 现在 → 新设计的对比；
- 未填写昵称、已有昵称（Jess / 小满）；
- 选了小图案、旧的表情头像被保留；
- 键盘打开；
- 设置页顶部的四种结果（未填写、首字、图案、旧表情）；
- 英文、375×667。

方向：Tactile Stationery × Cozy Editorial。像在给自己的手帐挑一张名字贴纸、一枚私人印章；精致、温和、成熟，不卡通，也不是社交账号设置。

## 1. 现状（代码核实）

- `Public/app.js` `settingsSheetHTML("profile")` 的结构：
  1. 标题「编辑资料」；
  2. 名字输入框，placeholder「想让 Little Days 怎么称呼你」；
  3. 「头像」区：一个首字按钮 + `Account.AVATARS` 里除 🌷 以外的 9 个系统 Emoji，5 列圆形网格（`.s2-avatars`）；
  4. 一行说明 + 「保存」。
- 动作：
  - `profile-avatar` 把选择放进 `profileDraft` 后整张面板重画；
  - `profile-save` 调用 `Account.signIn(localStorage, { name, avatar })`。
- `Public/js/account.mjs` 的保存规则：
  - 记录是 `little-days.account`：`{ version, method: "local", name, avatar, createdAt, signedIn, onboarded }`；
  - `signIn()` 只接受 `AVATARS` 里的值，其他值保留旧头像；
  - 默认 / 「没选」是 `"🌷"`。
- 设置页顶部 `.s2-me`：头像在 `avatar !== "🌷"` 时显示 Emoji，否则显示名字首字；没有名字时显示「L」和「还没有名字」。
- 其他用到头像的地方：
  - 登录 / 欢迎页（`loginHTML()`，仅实验室开启时）：同一组 `AVATARS` 的选择器。
  - 社区演示（实验室）：用的是 `little-days.demo-social` 里自己的 `profile.avatar`。登录时由 `Community.updateProfile` 复制一次，`community.mjs` 也只接受 `AVATARS`。它的个人页有「上传头像照片」（`avatarPhoto`，只在演示数据里）。
  - 共同创作演示（`collab-view.mjs`）：显示演示数据里的头像。
- 「编辑资料」**没有**上传照片的能力。

## 2. 新设计

### 2.1 版式（从上到下）

1. 顶部小横条（可下拉关闭），标题行：居中标题「属于你的小世界」17px/600，右上 36px 的 ×（与 Captain 面板、设置面板一致）。
2. **预览卡**：一张 256px 宽的小纸卡，微倾 −1.2°，顶部有一条半透明玫瑰色纸胶带，有轻投影。
   - 左边是 64px 的个人标记；
   - 右边是 10px 小字「MY LITTLE DAYS」（字距 0.16em），下面是名字和一条发丝线：英文用品牌衬线斜体 26px，中文用系统黑体 21px/600；
   - 没有名字时用浅灰写「我的小世界」；超过 9 个字时字号降到 21px；
   - 随输入和选择实时更新。
3. 一行副标题「一个名字，一枚专属的标记。」13px，`#675D54`，居中。
4. **名字**：标签 13px/600，输入框 48px 高、圆角 14、16px 字（避免 iOS 放大），placeholder「给自己起个喜欢的名字」，聚焦时 `--sageDeep` 描边加浅光晕。
5. **标记**：
   - 有旧的表情头像时，最上面先放一枚「现在的头像」小胶囊：44px 高，带那个表情和 ✓，可以再选回来。
   - 「字母印记 · 用名字的第一个字」一行 5 个；「小图案」一行 6 个。每个 48px（375 宽的屏幕上 44px）。
   - 选中状态：2px `--sageDeep` 外环，离开标记 4px。
   - 没有名字时，字母印记显示淡淡的「名」/「A」作样例。
6. **底部**：一行 12px「只保存在这台设备。」，下面是 50px 高的胶囊「保存」（`--sageDeep`）。底部随面板滚动时**固定在面板下沿**（sticky），在小屏上也始终够得到保存。

### 2.2 高度与键盘

- **高度跟内容走**，不占满屏幕。393×852 上约 626px（有「现在的头像」时约 680px），不会出现在顶部被裁掉的情况。
- **短屏**（高度 ≤ 700px，如 375×667）：
  - 预览卡缩小，标记从 64px 变 48px；
  - 标记键 44px；
  - 隐藏「只保存在这台设备」一行（设置页顶部已经写着）；
  - 保存键固定在底部。
- **键盘打开时**（输入框聚焦）：
  - 面板只留标题、缩小的预览卡（44px 标记）、名字输入框和保存；
  - 副标题和标记选择器暂时收起，面板约 308px 高；
  - 面板贴在键盘上沿（实现时用现有的 `--kb` / `visualViewport`，V10.5 Captain 面板已有同样机制）；
  - 输入框失焦后完整面板回来。

### 2.3 个人标记系统

**现在就能上线：字母印记（Monogram，5 种）**，取名字的第一个字（英文大写；中文取第一个汉字）：

| id | 样式 |
|---|---|
| `mono:paper` | 纸片：奶白圆形纸片 + 品牌衬线斜体字母（中文用小薇体），`--sageDeep` 色。这是**有名字时的默认**。 |
| `mono:seal` | 朱印：朱红双线圆环 + 朱红字。 |
| `mono:tag` | 标签：柔和圆角方纸片，内圈虚线（像打孔标签），深墨色黑体字。 |
| `mono:sage` | 鼠尾草底：实心 `--sageDeep` 圆 + 奶白字。 |
| `mono:script` | 手写：Caveat 手写体（中文用龙藏体），下方一笔赤陶色短线。 |

**默认（没有名字）**：嫩芽线稿 `mark:sprout`，呼应 Little Days 字标上的小芽；**不再显示「L」或任何 Emoji**。

**小图案（草稿 6 个，需要确认）**：嫩芽、小雏菊、书本、月亮、小枝、茶杯。
- 统一线条语言：48 网格、1.5px 圆头线、`--sageDeep` 主线；
- 只用一种点缀色（赤陶 `#B8734F`），用在嫩芽的地面、书签、星、热气、雏菊花心。

**我的判断（如实说明）**：
- 字母印记的完成度够，可以直接上线。
- 小图案是我用 SVG 画的草稿：干净、风格一致，但更像精致的界面图标，还不是「原创文具插画」级别的印记。书本、茶杯、月亮尤其接近常见图标；小枝偏单薄。
- **建议第一版只上线「字母印记 5 种 + 嫩芽默认标记」**。其余小图案交给设计师按下面的清单重画后再上（数据格式已经预留）。如果你觉得这批草稿可以接受，也可以先一起上。

### 2.4 怎么存（旧数据不丢）

- 字段不变：仍是 `little-days.account.avatar`（字符串），不新增账号概念，不改手帐、照片和媒体。
- 取值约定：

| 存的值 | 含义 | 显示 |
|---|---|---|
| `"🌷"`（旧的默认） | 没选 | 有名字 → `mono:paper` 首字；没名字 → 嫩芽 |
| `"mono:paper"` `"mono:seal"` `"mono:tag"` `"mono:sage"` `"mono:script"` | 字母印记 | 当前名字的首字。改名后跟着变 |
| `"mark:<id>"` | 小图案 | 对应图案；未知 id 显示嫩芽 |
| 旧的 Emoji（`🌼 🍓 🐰 🐱 🌿 ☁️ 📖 ☕ 🌙`） | 以前选过的头像 | 原样显示；面板里作为「现在的头像」保留，直到用户换掉 |

- `account.mjs` 需要改的地方：
  - `signIn()` 的白名单扩展为 `AVATARS` + `MARKS`（新增一个导出常量列出 mono / mark 的 id）；
  - 其他值仍保留旧头像（与现在相同）。
  - 新的选择器**不再提供** Emoji，但读取时永远认得它们。
- 「没选」继续存 `"🌷"`，不迁移数据。
- 渲染集中到一个函数（例如 `profileMarkHTML(account, size)`）：设置页顶部、面板预览、欢迎页共用。

### 2.5 其他地方保持一致

- **设置页顶部**（并行进行中的设置微调已采用同样的文案）：
  - 没有名字：嫩芽，名字行「我的小世界」，链接「给这个世界起个名字吧 ›」；
  - 有名字：首字纸片 + 名字 +「编辑资料 ›」；
  - 旧 Emoji 头像：原样。
- **欢迎 / 登录页**（实验室）：
  - 头像选择器换成同一套标记（字母印记 + 小图案），保留旧 Emoji 的读取；
  - 或者干脆只留名字输入、头像去设置里改。待你选择。
- **社区 / 共同创作演示**（实验室）：
  - 它们有自己的演示数据和白名单，`Community.updateProfile` 只接受 Emoji；
  - 建议同步时如果是 `mono:` / `mark:`，演示里显示同一个渲染结果（`community.mjs` 白名单相应扩展）；
  - 演示里的「上传头像照片」保持原样，不搬到正式资料里。
- **头像与 Captain 装扮互不影响**：`account.avatar` 与 `keeper.outfit` 是两条独立记录。

### 2.7 保存失败

- `Account.signIn` 写 localStorage 失败（存储已满或被禁用）时，不关闭面板，不显示「已保存」；
- 改为显示上表的失败提示，面板保持原样，可以再点保存；
- 现在的代码没有捕获这个异常。
