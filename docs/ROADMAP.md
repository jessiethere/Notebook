## V3.1 · 自由排版、多事件日记、完整回忆浏览与成长感想（本轮，Web）

P0 日历音视频阅读
- [x] Calendar 点有内容的日期打开只读 Day Detail：所有 Moments、照片排版、文字/贴纸、心情、自定义字段、Growth 打卡与感想。
- [x] 统一媒体卡片组件（编辑/只读两种模式）；设计感音频播放器（播放/暂停/进度拖动/时长），上传音频与录音均可播放；视频直接播放；照片点击放大。
- [x] 媒体从 IndexedDB 按视图加载（scope: app / studio / day），离开页面释放并撤销临时对象 URL；刷新、重选日期后重新载入。
- [x] 日历格子小圆点标记照片/视频/声音/成长，多个 Moments 显示数字，附图例。

P1 多照片自由排版
- [x] 一次多选最多 20 张、可继续添加不覆盖；每张照片独立图层（稳定 ID、媒体引用、相对坐标 x/y/w/h、缩放、旋转、裁切、相框、胶带、图层顺序）。
- [x] 单指拖动、双指缩放+旋转；鼠标拖角调整宽高、拖顶部圆点旋转、滚轮缩放（Shift 旋转）、方向键微调、Delete 删除。
- [x] 裁切模式（拖动平移、双指/滚轮/滑杆缩放）；替换、复制、删除、前后/逐层顺序；撤销/重做。
- [x] Auto Layout：双照片、三照片、四宫格、拍立得、拼贴；按照片数量建议版式；手动调整后切换模板先确认。
- [x] 旧主照片保留原固定版式，可一键“让主照片自由排版”；PNG 导出支持新照片图层、裁切、相框和成长卡片。

P2 多事件日记
- [x] Entry 作为日期容器新增有序 `moments`；Add a Moment，小标题/时间/正文/心情/标签/手帐本/纸张/字体/照片/视频/录音/自由画布。
- [x] 选择、上移/下移、复制、删除（可撤销）、折叠/展开；单独保存某个 Moment；整天保存。
- [x] Day Detail 按章节显示并有目录；My Books 按 Moment 所属手帐本列出章节。
- [ ] 一个 Moment 内部继续拆分多页（当前“页”= 当日主页 + 每个 Moment）。

P3 Growth 感想
- [x] 打卡小便签：内容、时长、感想、心情、可选照片；可重新打开编辑；默认私人，单独的“将来分享时允许显示”开关默认关闭。
- [x] 每周/每月回顾（做得好/困难/学到/改进），全部可选，可回看过去的回顾。
- [x] 成长卡片以引用方式插入 Studio，修改感想同步更新；不重复创建打卡，不重复计数；删除手帐页/Moment 不删除打卡；取消有感想的打卡前确认。
- [ ] 原生 SwiftUI 对齐上述 Web 能力（目前仅共享模型可解码）。

## Phase 2 · 明确标记的社区与社交原型

- [ ] Community、个人主页、Discover/Following/Popular/Categories/Search。
- [ ] 逐页/媒体确认的 Private → Public 发布界面、撤回、关闭评论。
- [ ] 点赞、评论/回复、收藏；收藏与复制授权分开。
- [ ] 关注、好友申请/接受/拒绝/取消、屏蔽/举报。
- [ ] 虚拟好友的会话列表、一对一模拟消息、时间/未读/删除。
- [ ] 本周/本月排序；主题筛选。
- [ ] 页面和数据都显式标注本地演示，无真实联网或好友访问权。

验收：默认私人；没有误发布；所有模拟状态可复现；双语完整；不把演示称为服务端安全或真实社交。

## Phase 3 · 真实社交后端

- [ ] Vapor 下验证数据库与对象存储方案，再落地迁移。
- [ ] 用户、认证/session、个人主页、服务端 owner/member 访问控制。
- [ ] 私有媒体对象、签名 URL、配额、格式检查、授权后下载。
- [ ] 公开作品快照、媒体逐项授权、关闭评论/撤回与删除传播。
- [ ] 互动、关注/双向好友、好友私信、未读与基本反骚扰。
- [ ] 屏蔽、举报队列、管理审计；数据删除、保留/恢复、备份演练。
- [ ] 自动化权限测试：匿名/非成员不能读私人日记、私信、媒体。

验收：通过真实服务端 401/403、对象级授权、撤销和数据恢复测试；不依赖客户端 visibility 字段保护私人内容。
