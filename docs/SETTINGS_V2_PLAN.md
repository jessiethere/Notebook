# Settings V2：视觉与信息架构（2026-11-11 · 设计已确认，V10.4 已实现）

设计稿：Design 画布 https://claude.ai/artifact/4tXVQfHSSPvQxJZqJFPTUG 的「Settings V2」一板：现在的设置整页、新设计整页、首屏（393×852）、页底、375×667（还没起名字）、英文。新设计是在真实 App 的设置页上注入原型后用 Chromium 截的；主题色板、Captain 图片来自真实页面，其余数值（存储大小、天数、提醒时间）是示意。

方向：Tactile Stationery × Cozy Editorial——像手帐最后几页的「个人资料与偏好」。不用大卡片连续堆叠：分组靠小标题、留白和发丝线；控件统一为一种开关、一种分段选择、一种文字链接、一种描边按钮。

## 1. 现状问题

- 12 张同样的大圆角卡片，整页约 4900px（393 宽）。
- 「更新记录」排在第 4 位、占 730px；「字体与素材许可证」「测试记录」「实验室」这些开发 / 测试信息与日常设置混在一起。
- 「账号」是一张通用信息卡：郁金香表情头像、「我」、两个大按钮（再看一次功能介绍 / 退出登录）。
- Little Keeper 卡片 750px：大段成长说明 + 名字输入 + 三个开关 + 关闭按钮，都摊在设置页里。
- 主题颜色是 6 张大卡片（350px）。

## 2. 「退出登录」到底是什么（代码核实）

- `Public/js/account.mjs`：没有服务器。所谓账号只是这台设备浏览器里的一条记录（名字、头像、是否看过引导）。`signOut()` 只把 `signedIn` 改成 false，**不删除任何手帐、照片或设置**。
- 启动时（`app.js`）：实验室关闭的普通安装没有登录页，发现未登录会**自动重新登录**。所以对普通用户，「退出登录」等于回到首页，没有实际作用；只有打开实验室时才会回到本机的欢迎 / 起名页。
- 结论：这不是真实的登录系统，现在的「账号 / 退出登录」字样有误导。新设计改为：
  - 顶部叫「My Capiday · 个人资料」，状态如实写「资料和手帐只保存在这台设备 · 没有云端账号」。
  - 「退出登录」改名为「回到欢迎页（数据保留）」，移到页面最下方的「关于与更多」，且只在实验室的登录页开启时显示。
  - 不暗示云同步；将来真有账号时再把这一区换成真实状态。

## 3. 新的信息架构（从上到下）

1. **个人资料**（无卡片，直接在纸色背景上，下方一条发丝线）
   头像（68px 圆形纸片：有自定义头像显示头像；没有时显示名字首字 / 品牌首字母，不再用表情符号）· kicker「MY CAPIDAY」· 昵称（没起名时显示「还没有名字」）· 一行本机状态 · 「编辑资料 ›」（名字、头像）。
2. **Little Keeper**（角色预览，不是介绍页）
   Captain 正式美术 64px · 名字 · 「温柔陪伴 · 新朋友」· 「角色与装扮 ›」（进入二级页：改名、成长说明、翻看以前的页面、主动打招呼等细项）· 一条四段选择：安静 / 温柔 / 互动 / 关闭 · 一行说明「和它互动在首页，这里只做设置」。
   不出现喂养、签到、等级进度条。
3. **外观与偏好**
   主题颜色：一行 6 个圆形三色色板（42px，当前项有 `--sageDeep` 外环和加粗名称）· 界面语言：中文 / English 分段 · 每天提醒：开关 + 时间和适用范围说明。
4. **数据与隐私**
   本机存储（只读一行：存了什么、在哪、媒体大小）· 备份与恢复（上次备份时间 + 两个描边按钮「备份到文件」「从备份恢复」；恢复仍先确认）· App 锁 · 首页隐藏今天的内容 · 分享时附上今日清单 · **AI 小管家**（标「尚未接入」，开关禁用，说明现在不发送任何内容、将来开启会单独征得同意）· 隐私说明（进入二级页，原来的四条说明全文）。
5. **关于与更多**（一组 50px 的细行，都带 ›）
   更新记录（有新版本时一个小红点 + 版本号）· 功能介绍（再看一次）· 字体与素材许可证 · 示例内容（N 天示例 → 移除）· 导出测试记录 · 实验室 · 回到欢迎页（仅实验室登录页开启时）。
6. **页尾**：品牌衬线「Capiday」+ 版本号和一句话。最后一项下方留出底部导航的高度，不被遮挡。

整页从约 4900px 降到约 1950px；首屏能看到个人资料、Keeper 和主题色板。

## 5. 视觉与交互规范（实现时写入 DESIGN_SYSTEM）

- 分组标题 17px / 600（英文界面用品牌衬线斜体 22px），上方留 30px；行高最小 56px（次要行 50px），行间一条发丝线，不套卡片。
- 行内文字：名称 15px / 500，说明 13px `#675D54`，最小字号 12px。
- 开关 48×28，开启为 `--sageDeep`；分段选择底色 `#EFE7DA`、选中为纸色加轻投影；文字链接 14px / 600 `--sageDeep`；描边按钮 44px 高、胶囊形。
- 危险或不可逆操作（恢复备份、移除示例、回到欢迎页）都保留现有的页面内确认（`askConfirm`），失败时保留现有错误提示。
- 所有可点区域 ≥ 44px；不加与设置无关的装饰和动画。

## 6. 实现可行性

- 只改 `settingsHTML()` 的模板与样式，所有 `data-action` 和处理函数不变；不动数据。
- 需要迁移的测试：依赖 `.settings-card`、Keeper 设置开关、主题按钮、更新记录卡片位置的用例（估计 8–10 套：v36、v52、v63、v68–v71 等）。
- iOS 外壳加载同一份页面，无需另做 SwiftUI。未在真机 / Safari 验证。
