> 2026-11-12。来源：用户「Journal Studio Information Architecture Cleanup — Creative Freedom Without Complexity」。

## 2. 新的三层结构

- **第 1 层：创作工具**（默认，固定）：照片 · 文字 · 贴纸 · 更多。手绘放在「更多 → 媒体与创作」的第一个，浅绿底突出显示；实际用下来如果很常用，再考虑提到第一层。
- **第 2 层：选中对象的工具**。最左边一律是「‹ 返回」（回到创作工具），点纸上空白处也能返回。
  - 照片：形状 · 裁剪 · 调整 · 替换 · 图层 · 删除
  - 文字：编辑 · 字体 · 颜色 · 对齐 · 图层 · 删除
  - 视频：播放（新）· 封面 · 形状 · 图层 · 删除
  - 贴纸：换一个（新）· 图层 · 删除
  - 手绘 / 声音 / 打卡卡片：再画或播放 · 图层 · 删除
  - 形状、字体、颜色、对齐、图层改为工具栏上方的细选项条（约 110–150px，只有标题和 ×），纸只缩一点。
  - 裁剪、调整、手绘仍用全屏编辑页。
- **第 3 层：更多，分三组**。点一个工具，就在同一个面板里打开它：左上 ‹ 回到「更多」，右上 × 关闭。
  - A 页面外观：背景与纸张 · 排版 · 页面字体 · 写法
  - B 媒体与创作：手绘 · 视频 · 音频 · 背景音乐 · 本页媒体
  - C 页面管理：页面信息 · 心情（快捷入口，打开页面信息里的心情一段）· 页面目录 · 操作指南
  - 有打卡或自定义记录项目时，C 组多出「打卡卡片」「记录项目」。

| 功能 | 主入口 | 保留的快捷入口（打开同一个面板、用同一套逻辑） | 去掉 |
| --- | --- | --- | --- |

| 添加照片 | 底部「照片」 | — | 更多 → 本页照片 |
| 视频 / 音频 | 更多 → 视频 / 音频 | 本页媒体只管理已有的 | 本页媒体里的添加按钮 |
| 背景 | 更多 → 背景与纸张 | — | 添加照片面板里的「换个页面背景」 |
| 字体 | 两个都保留 | — | 整页的那个改名「页面字体」 |
| 心情 | 页面信息 → 心情 | 更多 → 心情 | — |
| 排版 | 更多 → 排版 | 「试试排版」提示 | 「版式」这个名字 |

## 5. 面板规则与名称

- **面板规则**
  - 标题就是打开它的那个按钮的名字。
  - ‹ 只在第 3 层出现，表示回到「更多」。
  - 右上角 × 关闭面板，已做的改动保留。
  - 删除一律用 🗑 加文字，红色。
  - 第 2 层不显示 ‹，切换工具不用先关。
  - 核心选项放在最上面；滑杆收进「精确调整 ▾」。
  - 换到别的工具时回到顶部；同一个工具刷新时保持原来的位置。
  - 需要大预览的操作用全屏页面。
  - 面板默认紧凑，纸始终在面板上方。
  - 每一步都能撤销。
  - 375 宽时一排最多 7 个按钮，每个至少 44px。
  - 键盘弹出时只显示打字样式条；底部留出 Safe Area。
- **名称**
  - 排版：几张照片之间怎么排。
  - 形状：照片外框的样子。
  - 裁剪：照片里保留哪一块，不改动原图。
  - 调整：亮度、对比度、色彩、滤镜。
  - 背景：整页最底下的一层；纸张 / 纯色 / 图案 / 照片四选一，选新的直接替换。
  - 心情：这一页可选的标记，不画到纸上、不计分。
  - 写法：照片 + 一句 / 随手写 / 自由排版。
  - 页面字体：整页的标题和正文。

## 6. 首次教程

沿用 V10.12 的指南框架：指着真实按钮、可以跳过、只自动出现一次、可从「更多 → 操作指南」重看。内容换成四步：

1. 加东西：照片 · 文字 · 贴纸。
2. 摆位置：点一下选中，拖动移动，双击文字直接改。
3. 改它：选中后，下面就是它的工具；‹ 回到创作工具。
4. 改整页：背景、排版、手绘、页面目录都在「更多」里。
