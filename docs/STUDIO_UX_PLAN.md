# Journal Studio 交互重设计（方案，待用户确认；尚未实现）

> 2026-11-11 记录。来源：用户「Little Days V9.0 — Journal Studio UX Redesign」。**本轮只有设计稿，没有改代码。**
> 设计稿（Design 画布，私有）：https://claude.ai/artifact/4tXVQfHSSPvQxJZqJFPTUG → 「Journal Studio · 新的三种编辑状态」一行 9 张板。
> 方向：Creative Freedom Without Complexity；视觉沿用 Tactile Stationery × Cozy Editorial。功能一个不删，只重新安排层次。

## 1. 三种状态

- **A 默认画布**：顶部 = 返回 · 页面名 + 「第 n 页 · 共 m 页 ▾」+ 保存状态点 · 预览 · 完成；中间 = 尽量大的 4:5 纸；纸面左下 = 撤销 / 重做，右下 = 页点 + 「＋」加一页；底部一排 = 照片 · 文字 · 贴纸 · 更多。空白纸只有一个「放第一张照片」占位和「或者点一下纸面，直接写字」。
- **B 选中对象**：底部同一排换成该对象的操作，最左是「✕ + 对象类型」（取消选择）。照片：替换 · 裁剪 · 调整 · 图层 · 删除；文字：编辑 · 字体 · 颜色 · 对齐 · 删除；贴纸：替换 · 尺寸 · 旋转 · 图层 · 删除。需要选项时在这一排上方出一条细选项（字体条 + 大小滑杆、颜色条、对齐三选一、图层：上移 / 下移 / 置顶 / 置底 / 复制）。画布中央不再有黑色浮动菜单。拖动、双指缩放 / 旋转、撤销 / 重做保留。
- **C 更多**：一张底部面板，八个工具（背景与纸张 · 版式 · 手绘 · 视频 · 音频 · 心情 · 页面管理 · 页面信息）+ 「换一种写法」+（有内容时）「这本手帐的记录项目」「当天打卡感想」。每个工具都在同一张面板里打开，左上角返回，随时关闭。
- **纸不动**：A / B 下纸的位置和大小不变（纸面与底部工具之间预留给 B 的细选项条）；C 打开时纸缩小停在上方。

## 2. 页面管理与 Page Details

- 点顶部页面名 → 页面管理：这一天的封面和各页缩略图、加一页、按住拖动排序、点一页去编辑；当前页的「页面信息 / 复制这一页 / 删除这一页」。
- 页面信息：这一页的名字、记到哪本手帐、日期、时间、页面下方的说明、保存状态、删除这一页。
- 页与页之间也可以在纸上左右滑动切换。

## 3. 保存

- 自动草稿：沿用现有机制（改动后约 1 秒存草稿；媒体在 IndexedDB）。
- 顶部状态点：已保存 / 保存中… / 没保存上 · 点这里重试。
- 「完成」= 现在的「保存」：正式存成这一页，成功后才退出并显示保存后的那一页；失败则留在编辑器并可重试。
- 返回：草稿仍在；有没保存上的改动时先问「再试一次 / 先留着草稿离开」。
- 导出 / 分享移到「预览」页（分享 · 导出图片 · 导出视频）。

## 5. 需要用户确认 / 实现时注意

1. 撤销 / 重做放在纸面左下角（用户给的顶部清单里没有它们）是否可以。
2. 「完成」是否就等于现在的「保存并离开」（保存后仍显示保存后的那一页）。
3. 「照片 + 一句 / 随手写」两种写法在纸上直接打字的方式保留；它们的标题、正文是否也要支持选中后的上下文工具（建议：字体 / 颜色 / 对齐可用，位置不可拖）。
4. 实现建议分两步：先换外壳（顶部、底部工具、更多面板、页面管理 / 信息，旧面板内容原样搬进新面板），再做选中对象的上下文工具条。43 套浏览器测试里大量依赖现有选择器，需要逐套迁移。
5. 不恢复独立 Growth 模块；Keeper 不常驻编辑器。


## 6. 用户确认（2026-11-11）与实现状态

用户的决定：

1. 撤销 / 重做放在纸张左下方、画布之外的固定区域；不可用时显示禁用；照片、文字、贴纸、位置、图层修改都进入历史；切页后不能改到其他页面；顶部不放撤销 / 重做。
2. 「完成」= 保存成功并离开编辑，显示刚保存页面的只读视图（可再进入）；编辑中自动存草稿；顶部显示 已保存 / 保存中 / 保存失败；失败时留在编辑器、保留修改、可重试；不自动发布。
3. 「照片+一句 / 随手写」的标题和正文可改 文字、字体、字号、颜色、对齐；位置保持自动排版、不可拖；提供「转换为自由文字框」，转换不丢文字和样式、不重复。
4. 分两步：Phase A 外壳 → 回归 → Phase B 上下文工具 → 回归。
5. 视觉沿用 Tactile Stationery × Cozy Editorial，不另起一套。

实现状态：

- **Phase A（V10.0，已完成）**：顶部栏、底部四个工具、更多面板、页面管理（页面名 / 更多）、页面信息、撤销 / 重做移到纸张下方并按页面隔离、保存状态与失败重试、完成 → 只读页、预览（分享 / 导出）。旧面板内容原样搬进新面板。黑色浮动菜单暂时保留。
- **Phase B（V10.1，已完成）**：选中照片 / 文字 / 贴纸 / 视频 / 手绘时底部换成对应工具，黑色浮动菜单取消；文字框的字体 / 字号 / 颜色 / 对齐面板和「编辑」（纸上直接打字）；Quick Create 标题 / 正文在打字工具条里改字体 / 字号 / 颜色 / 对齐，并有「转为自由文字框」（保留样式、不重复、可撤销）；复制与层级顺序收进「图层」。
- **仍未做（与设计稿的差异）**：页面管理的缩略图网格与拖动排序、页面信息的新表单样式（现在是旧面板搬进新 Sheet）；字体条 + 字号滑杆直接叠在工具上方的形式（现在是 Bottom Sheet + A− / A+）；纸面上的裁切框（现在是滑杆）；贴纸「替换」。均未在 iPhone 真机 / Xcode 验证。
