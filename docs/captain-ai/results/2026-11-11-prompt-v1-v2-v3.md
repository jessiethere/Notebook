- v2 去掉了「喵」、表情和劝写，但提示词里举的例子（「胡须、尾巴、有阳光的窗台」）和「你戴着柠檬帽」这一行变成了新的口癖。还出现了把夸奖说反（「你的柠檬帽真好看！」）和按注入指令改说英文。
- v3 不给可以反复用的具体意象；帽子只在对方提到时才说；明确「夸奖是在夸你」；拒绝换语言。口癖基本消失。
- 注入那句：4B 模型被要求「用英文写」时，v2、v3 都会照着改用英文，而且 v3 有一次对英文输入用了中文回复。提示词压不住，所以**在代码里拦截**：`sameLanguage(said, reply)` 判断回复和用户那句的语言不一致时丢弃，App 改用规则回复（`createLocalProvider().reply()` 抛错 → `keeperReply()`）。
